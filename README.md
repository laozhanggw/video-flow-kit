# 视频流程套件

一套「一个人做英文 YouTube 改造类 Shorts」的生产流程规范。七段：拆解 → 复刻 → 开头 → 小分镜 → 生产单元 → 生成 → 复盘。

**给同事：先看 [`00_先读我.md`](00_先读我.md)，再看 [`02_操作流程_图解.html`](02_操作流程_图解.html)（双击就开，带流程图）。**
**给 AI：整份丢 [`01_给AI的接手指南.md`](01_给AI的接手指南.md)。**

**给主管工与流程维护 AI：先读 [`48_流程维护与发布_给所有AI.md`](48_流程维护与发布_给所有AI.md)。** 根层另有 `AGENTS.md`、`CLAUDE.md` 短入口；是否自动加载取决于宿主，旧对话不会自动刷新。作者源目录和下载副本不同，修改与公开发布也不是同一步。

---

## 这套东西现在是什么口径（2026-10-27 定稿，全部对齐阿初）

| 层 | 回答哪句话 | 规则 |
|---|---|---|
| 分镜 | 成片怎么剪 | 一刀只演一件事；每刀写两个秒数：**素材秒**（拍完要几秒）、**成片秒**（剪完占几秒） |
| 生产单元 | 一次生成装多少 | 一组 ＝ 一次生成 ＝ **13–15 秒装满，装 6–7 刀，每刀约 2 秒** |
| 提示词 | 盒内怎么演 | 每刀一个机位、一个动作；切点两侧**必须换景别**；每处切点单独写一行硬切 |

**三个数背下来就够：13–15 秒、6–7 刀、每刀约 2 秒。**
刀数不是规定值，是除出来的：**生成秒数 ÷ 2**。
剪裁比全项目只有一个：**0.867**（生成 15 秒 → 成片 13 秒）。

## 已经作废的旧规矩（看到就当没看到）

一盒 4–10 秒 · 一盒 2–4 刀 · 一盒一个工序 · 最多两件事 · 每刀不少于 2 秒 · 刀数上限 ·「12–15 秒必废」。
它们错在同一处：拿一次「单镜头长盒丢件」的实测，当成了通用规律。

## 目录

| 目录 | 是什么 |
|---|---|
| `指令/` | 五份可直接复制的指令（01 拆解／02 复刻／03 开头／04 小分镜／05 生产单元） |
| `skills/` | 七个 skill，四个环节的细则在这里 |
| `模板/` | 新项目空目录骨架，第一次真跑时整套复制 |
| `tools/` | 配置本机路径、重新生成流程导图、自检引用 |
| `流程导图.html` | 可点开的完整流程图，**五份指令全文内嵌**，可直接发给别的 AI |
| `对标库/` | 放对标拆解结果（空目录） |

## 用之前先做一次

双击 `tools\设置本机路径.bat`，把这份套件在你电脑上的位置填进去。**只做一次，不用改任何文件。**

## 改完东西记得重跑

指令 `.txt` 是网页（`流程导图.html`）的来源，改完必须重新生成，否则人从网页复制的还是旧规则：

```
python tools\生成流程导图.py
```

跑完核对：网页底部显示的字数要和磁盘上一致。
