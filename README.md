## 这套东西现在是什么口径（2026-10-27 定稿，全部对齐阿初）

| 层 | 回答哪句话 | 规则 |
|---|---|---|
| 分镜 | 成片怎么剪 | 一刀只演一件事；每刀写两个秒数：**素材秒**（拍完要几秒）、**成片秒**（剪完占几秒） |
| 生产单元 | 一次生成装多少 | 一组 ＝ 一次生成 ＝ **13–15 秒装满，装 6–7 刀，每刀约 2 秒** |
| 提示词 | 盒内怎么演 | 每刀一个机位、一个动作；切点两侧**必须换景别**；每处切点单独写一行硬切 |

以上为 2026-10-27 的历史概览；具体刀数、素材秒和预算按当前完整指令及其引用文件执行，不以本段覆盖新版规则。0.867 是现行预算假设，不是全部视频已经验证的固定取用率，也不等于真实播放倍速。

## 已经作废的旧规矩（看到就当没看到）

一盒 4–10 秒 · 一盒 2–4 刀 · 一盒一个工序 · 最多两件事 · 每刀不少于 2 秒 · 刀数上限 ·「12–15 秒必废」。
它们错在同一处：拿一次「单镜头长盒丢件」的实测，当成了通用规律。

## 用之前先做一次

需要本机 Python 3.10+、Pillow 和可用中文字体，不是零环境直接运行，也不捆绑作者环境。在套件根目录用 Windows 命令提示符执行：

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install Pillow
.venv\Scripts\python.exe tools\设置本机路径.py
.venv\Scripts\python.exe tools\自检引用.py
```

也可在确认解释器依赖齐全后双击 `tools\设置本机路径.bat`。配置会递归更新根规则、指令、skills、模板并重生成导图；Python 工具自行定位，不填脚本正文路径。不会自动安装依赖或从初次备份还原文件；搬家后重建本机虚拟环境，再运行配置与自检，安全更新旧 ROOT。

ffmpeg/ffprobe 仅在媒体探测、抽帧或成片检查时必需；安装并加入 PATH 后执行 `.venv\Scripts\python.exe tools\自检引用.py --media`。未执行的媒体检查必须标「未执行」，不算通过。

使用分发包不需要 Git、GitHub 或作者账号；作者同步脚本不随包是正常的。VisualGPT 等外接导入/生产程序需用户自行配置，缺省仅交付生产表与核对清单，不代表已接通平台或登录态。
