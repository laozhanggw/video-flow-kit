## 三、任务 1：修 `检查_拆解.py` 的两处缺陷

文件：`E:\智线出海内容运营\09 工具\检查_拆解.py`（约 145 行，纯标准库，无外部依赖）

### 1a 「观众第一反应」判定方式错了

**现状代码（第 99–101 行附近）：**

```python
    hit = [r for r in REACTIONS if r in t_head]
    rows.append(('观众第一反应（三选一）', hit[0] if hit else '没填', '三选一',
                 len(hit) == 1, '只能填一个，且不许用形容词'))
```

**问题：** `len(hit) == 1` 要求**整份文件里三个选项词只出现一个**。只要交付物在说明、表格或脚注里把三个选项并列写出来（这是正确行为），就判 FAIL。

**已复现：** 在 B0001 的 `02_开头拆解.md` 末尾加一行
`> 观众第一反应三选一：必须马上处理 / 可以忍但不好看 / 看着舒服`
该项从 `PASS` 变成 `FAIL`。

**改成：只认「观众第一反应」这一行，不看别处。**

判定步骤：
1. 找出所有以 `观众第一反应` 开头的行（允许行首有 `*`、`-`、`>`、空格、`|`、`**`）。
2. 取该行**最后一个** `：` 或 `:` 之后的文本，截到行尾或第一个 `｜`/`|` 为止。
3. 去掉首尾空白、`*`、全角空格、句号。
4. 该值必须**完全等于** `REACTIONS` 里的某一个（用 `==`，不要用 `in`）。
5. 若该值里同时出现两个以上选项（用 `/`、`／`、`、` 分隔），判 FAIL，提示「只能写一个，不要并列」。
6. 文件里其它行出现这三个词，**不影响判定**。

### 1b 「问题物占比」只验有没有百分号，不验数值

**现状代码（第 92–96 行附近）：**

```python
    m = re.search(r'问题物[^\n]*\n?\|?[^\n]*', t_head)
    seg = t_head[t_head.find('问题物'):t_head.find('问题物') + 400] if '问题物' in t_head else ''
    pct = re.search(r'\d+(?:\.\d+)?\s*%', seg)
    rows.append(('问题物写了画面占比', pct.group() if pct else '没找到 %', '必须有 %',
                 bool(pct), '写「数十片」不算，必须给占画面百分比'))
```

**问题：** 只要「问题物」后 400 字里出现任意 `数字%` 就算通过。

**已复现：** 在 `问题物` 那一行下面插入「（问题物占全画面 0.1%）」，该项 `PASS`——而这条片子的真实值是 25.0%。**写 0.1% 和写 25.0% 结果一样。**

**改成：认固定写法 + 校验取值范围。**

判定步骤：
1. 正则 `问题物占全画面\s*(\d+(?:\.\d+)?)\s*%`，在整份文件里找。
2. 一处都没找到 → FAIL，提示「必须写成『问题物占全画面 XX.X%』，不许写『约两成』『数十片』」。
3. 找到但数值 `< 0.5` 或 `> 100` → FAIL，提示「数值 <实际值>% 超出合理范围，请重新数像素」。
4. 找到多处且数值不一致 → FAIL，提示「占比出现两个不同值：<值1> / <值2>」。
5. 通过时，`实测` 列显示匹配到的完整字符串（例如 `问题物占全画面 25.0%`）。

### 不许做

- 不改另外 6 项判定的任何逻辑、阈值、文案。
- 不改 `TOOLS`、`REACTIONS` 常量的内容。
- 不改退出码约定（0 全过 / 1 有不过 / 2 出错）。
- 不做重构，不拆函数，不换输出格式（表格列宽、`PASS`/`FAIL` 字样都保留）。
