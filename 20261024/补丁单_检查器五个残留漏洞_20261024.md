## 漏洞 1：「观众第一反应」写两个不同选项，判过

**现状**（第 133–137 行）：

```python
    multi = [v for v in cands if sum(r in v for r in REACTIONS) >= 2]
    exact = [v for v in cands if v in REACTIONS]
    if exact:
        rows.append(('观众第一反应（三选一）', exact[0], '三选一', True,
                     '只能填一个，且不许用形容词'))
```

`exact` 是列表，取了 `[0]`。所以文件里写

```
**观众第一反应：必须马上处理**
**观众第一反应：看着舒服**
```

**两行都合法，判 PASS，静默取第一行。** 这和改之前的「随便命中一个词就算过」是同一类问题：不唯一时不报错。

**已复现：** 上述两行同时存在 → `观众第一反应（三选一）= 必须马上处理 / PASS`。

**改成：出现两个不同值判不过。**

在 `if exact:` 之前加去重判断：

```python
    uniq = []
    for v in exact:
        if v not in uniq:
            uniq.append(v)
    if len(uniq) > 1:
        two = ' / '.join(uniq)
        rows.append(('观众第一反应（三选一）', two, '只能一个值', False,
                     '写了两个不同的选项：' + two))
    elif uniq:
        rows.append(('观众第一反应（三选一）', uniq[0], '三选一', True,
                     '只能填一个，且不许用形容词'))
    elif multi:
        ...（原有的 multi / cands / else 三个分支保持不动）
```

注意：同一个值重复出现两次（如两处都写「必须马上处理」）**仍然算过**，那不是矛盾。

## 漏洞 2：占比写成中文冒号，报「没找到固定写法」

**现状**（第 92 行）：

```python
    pat = re.compile(r'问题物占全画面\s*(\d+(?:\.\d+)?)\s*%')
```

中间不允许冒号。所以写成

```
问题物占全画面：25.0%
```

**判 FAIL，而且理由是「没找到固定写法」**——内容明明对，只是多了一个冒号。这会让人以为数值没写，实际只是标点。

**已复现：** 只写 `问题物占全画面：25.0%` → `问题物写了画面占比 = 没找到固定写法 / FAIL`。

**改成：冒号可选。**

```python
    pat = re.compile(r'问题物占全画面\s*[:：]?\s*(\d+(?:\.\d+)?)\s*%')
```

其余判分逻辑（去重、双值、0.5–100 范围）一个字不动。

## 漏洞 3：情绪弧还在用 600 字固定窗口

**现状**（第 149–150 行）：

```python
    emo = t_head[t_head.find('情绪弧'):t_head.find('情绪弧') + 600] if '情绪弧' in t_head else ''
    num = re.search(r'(?:难受|强度)\s*[:：]?\s*([0-3])|[:：]\s*([0-3])\s*[）)]', emo)
```

只从**第一个**「情绪弧」往后扫 600 字。真实的 `02_开头拆解.md` 里，情绪弧常常是一张 7 段以上的表，`强度：N` 排在表格末尾——很容易超过 600 字，于是**内容写对了却判不过**。

这正是上一轮从「占比」里删掉的那个「400 字窗口」，这里还留着一个。

**已复现：** 情绪弧标题 → 15 行表格（约 2,000 字）→ 末尾写 `强度：2`，实际距离第一个「情绪弧」2,029 字 →
`情绪弧带难受程度 0–3 = 没找到 / FAIL`。

**改成：按小节切，不用定长窗口。**

```python
    # 5 情绪弧带 0–3（按小节切，不用定长窗口）
    emo = ''
    i = t_head.find('情绪弧')
    if i >= 0:
        m2 = re.search(r'\n#{2,6}\s', t_head[i + 3:])
        j = i + 3 + m2.start() if m2 else len(t_head)
        emo = t_head[i:j]
    num = re.search(r'(?:难受|强度)\s*[:：]?\s*([0-3])|[:：]\s*([0-3])\s*[）)]', emo)
```

`#{2,6}` 是为了同时兼容 `##`、`###`、`####` 小标题；到下一个标题为止。

**改成：新增第 8 项判定。**

```python

    seg = t_head[t_head.find('人物'):t_head.find('人物') + 700] if '人物' in t_head else ''
    need = {
        '人数': bool(re.search(r'\d+\s*人|人数', seg)),
        '年龄外观': ('岁' in seg),
        '人脸特写次数': bool(re.search(r'人脸特写|特写\s*[:：]?\s*\d+|\d+\s*次', seg)),
        '正脸:侧脸:背影': bool(re.search(r'\d+\s*[:：]\s*\d+\s*[:：]\s*\d+', seg)),
```
