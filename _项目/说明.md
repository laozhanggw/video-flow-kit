# 项目

每一条新片子建在这里。一个批次一个文件夹。

```
_项目\
└─ 20261022_B0007_雨天收衣\        ← 批次
   ├─ 01_中间过程稿.md
   ├─ 00_批次总览.md
   ├─ V01_对照版\                   ← 版本
   │  ├─ 00_版本设定书.md           ← 这一段的核心，下游全看它
   │  ├─ 开头\
   │  ├─ 分镜\
   │  ├─ 单元\
   │  ├─ 生成\
   │  └─ 说明\
   └─ V02_xxx\
```

建新批次时，把 `模板\` 里的 `00_版本设定书_空表.md` 和 `_V文件夹骨架\` 复制过去。
具体怎么填，看 `模板\00_怎么用.md`。

第一次用是空的，正常。
