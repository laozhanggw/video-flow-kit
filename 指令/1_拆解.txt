  ★「骨架一句话」——**固定三段式，三段都是因果链，句子里一个数字都不许有，缺一段算没交**

    改造：<谁> 动手，把 <什么> 整个换掉或修好，<中间有没有返工>

  ★「对账四元组」——紧接在骨架下一行，单独一行写，缺了算没交

    X=__%（问题物占首帧画面）／N=__ 个动作／T=__ 秒（改造段）／根治 __ 项＋升华 __ 项

    写法硬规定：
    · **骨架的三句话里，不许出现百分比、秒数、动作数、项数。**
      数字全部只出现在「对账四元组」那一行。这一条不许绕过。
      理由：带数的句子看不出哪一拍可以动。阿初的骨架是纯因果链——
      「主角被坏人追逐抓住-被欺负后无力的反击-在要被伤害前被好人阻止-好人打跑了坏人-好人无视了主角」，
      一个数都没有，但谁做了什么都清楚。
      用他的白模测试自检：**刨去外观、刨去背景、刨去道具、刨去一切，
      当所有都是白模，这段视频到底说了什么？** 答得出来才算骨架。
    · **三段必须各自说清「谁」。** 改造前是谁受害，改造是谁动手，改造后是谁在用。
      「谁动手」这一拍不许省：原片是施工队、是当事人自己、还是邻居来帮，
      这一拍决定整条片子的性质，省掉了骨架就变成「状态从 A 变 B」，不是故事。
    · 四元组里的 X、a、b、N、T 必须与本文件【文件三】表 3 的占比、
      【文件四】的终局兑现链完全一致，不许另算一套。
    · 观众反应只能填：`必须马上处理` / `可以忍但不好看` / `看着舒服`
    · 禁止写成动作流水账。「暴雨打进来 → 捡叶 → 冲地 → 刷墙 → 挂帘 → 摆家具 → 空镜」
      这种是流水账，不是骨架：它只有「做了什么」，没有「差到什么程度」和「根治了什么、升华了什么」。
    · 写不出 X% 就先回头算，不许用「很乱」「特别脏」「乱到极致」这类形容词顶替数字。

【文件三】02_开头拆解.md —— 一节人读 ＋ 六张表 ＋ 一段冲突强度，一样都不许缺

  ★ 「开头方案（人读版）」—— 放在全文件最前面，**不参与下面 1）2）那套编号**，缺这一节算没交

    这一节是给人看的，不是给机器判分的。不超过 250 字，不许放表格。
    写成能直接照着拍的样子，必须回答六件事：

      · 几秒、几个镜头、要不要一镜到底
      · 画面里在发生什么（一句话）
      · 机位：高度几米、俯仰几度、焦段、人占画面几成
      · 那一个动作：起点状态 → 终点状态
      · 前 3 秒里"消失的东西"一共出现了几次、在哪几秒
        （从下面 2b）微段表里数出来，给数。**这一句里不要再写"微段表"三个字**，
         写「从下面的细账数出来」就行）
      · 为什么这样开头能留住人（一句话，说机制，不许说「很抓人」）
      · 这一段的硬约束是什么（一句话：哪几件事必须一模一样，改了就塌。
        只说原片，不说我们怎么改——怎么改由复刻那一段决定）

    写完这一节，再接下面的五张表。表是给下游抄的，这一节是给人读的。

  1）逐镜表
     段 / 起止秒 / 画面一句话（谁＋在干什么＋东西什么状态＋景别·机位·运动）/ 环节
     / **表情·视线** / **状态变化（从什么变成什么）** / **动作数** / **位移**

     后三列与【文件四】同口径，是复刻写设定书 4.5 节的直接来源，缺了下游只能靠猜：
     ·「景别·机位·运动」三样缺一不可：景别（特写／近景／中景／全景／远景）＋机位（高度几米、俯仰几度）＋运动（固定／推／拉／摇／移／跟／手持，写清方向）。只写「中景」不算填。
     ·「状态变化」写「从 X 变成 Y」。一次可见变化算一次；同一动作只换机位、不另算。
       原片开头两镜经常是同一个动作的两个机位（中景看人 → 广角看空间），那种情况动作数是 1，不是 2。
     ·「动作数」按状态变化数计，不按手部步骤数。原片每镜通常是 0 或 1，空镜写 0。
     ·「位移」写是/否：人带着东西在空间里移动＝是。写「是」的镜，下游要给它足够的**素材秒**（走完这段路要几秒就写几秒），**不设最小时长**——「≥2 秒」是剪辑规则，不是拍摄规则。
     ·「表情·视线」写这一镜里人往哪儿看、脸上是什么状态（例：低头盯着脚下、皱眉、回头看镜头、只给背影不露脸）。背身或空镜写「无」。这是情绪弧五通道的第①项——情绪弧里按它判了，这一列就必须有账，不许判了不记。

  2b）**开头微段表（0.2 秒一格，强制，不许合并）**
      （编号叫 2b 是跟着「1）逐镜表、2）七段环节表」这套走的；
       你写成 1b 也能过闸门，但同一份文件里别两种混用）

     逐镜表按切点分，一镜到底的镜头只有一行 —— 那就是「0–3.1 秒粗拆一下」，不行。
     **开头段必须再拆一层微段表：从 0.000 秒到 T_钩，每 0.2 秒一行，一秒 5 行，一行都不许少。**

     | # | 起止秒 | 这一格新增了什么 | 消失／减少了什么 | 手在哪、在做什么 | 身体姿态与朝向 | 构图变化（机位怎么动） | 观众这一格看到什么 |
     |---|---|---|---|---|---|---|---|

     写法硬规定：
     · **格子数 = T_钩 ÷ 0.2，上下取整。** T_钩 3.1 秒 → 16 格（0.0–0.2 … 3.0–3.2）；8 秒 → 40 格
     · **一格都不许合并。** 连着几格"没变化"也要各占一行，写「无新增，手前伸约 20cm」这种
     · 「新增了什么」写具体东西：第几把叶子、袋子涨到几成、水面露出一块砖、
       墙面刷出一道白、雨丝方向变了。**不许写「继续捡叶」「画面无变化」**
     · 「消失／减少了什么」是这条片子的爽点来源，**必须每格都问一遍**：
       这一格叶子少了多少、水退了多少、霉斑小了多少。没有就写「无」
     · 「手在哪」要写手相对于身体和画面的位置（例：右手伸到左膝外侧、离地 30cm）
     · 「观众这一格看到什么」写观众感知，不写判断（例：看到地上少了一片，看到袋子沉下去）
     · **一格的字数控制在 20–45 字。写不下就是拆得不够细，写太长就是掺了废话。**

     为什么必须这样拆：一镜到底的长镜头里，观众看到的不是"一个动作"，
     而是**几十次微小的消失**。那几十次消失才是他留下来的原因。
     按镜头拆，这些全部被压成一句话，下游复刻时根本不知道该在第几秒给出什么。

     上面逐镜表是"有几刀"的账，这张微段表是"前几秒里到底发生了什么"的账。
     两张表都要有，不许互相替代。逐镜表在微段表里查细节，微段表在逐镜表里对秒数。

  2）七段环节表
     问题出现 / 第一反应 / 决定动手 / 连续修 / 再测试 / 这次没事 / 收尾
     有的标起止秒；没有的写「无」，并注明「照抄时不许补」

  3）表面清单十项
     地点 / **问题物（四件套：占比 ＋ 分布 ＋ 处数类数 ＋ 大小形状）** / 天气 /
     **人物（四件套：人数＋年龄外观＋人脸特写次数＋正脸:侧脸:背影比例）** / 穿着 / 工具 / 材料 / 修法 / 画面文字 / 声音

     「问题物」这一项**必须按四件套写，缺一件算没交**：
      占比必须写成固定串：`问题物占全画面 25.0%`。
      不许写「约两成」「数十片」「满院子都是」。
       · **占比**：占 0.000 秒首帧画面的百分之几。
         **唯一单位是画面百分比，不是片数、不是件数、不是堆数。**
         算法：打开 `01_原片证据\first_frame-001.jpg`，数目标物像素 ÷ 全画面像素。
         拿不到首帧 → 写「占比未核」并说明卡在哪，不许用约数顶。
       · **分布**：铺满 / 成堆 / 散落 / 集中一处（可多选，必须写清在画面的哪一片）
       · **处数类数**：共几处、分几类。**写「处」和「类」，不写「数十片」这种约数。**
       · **大小形状**：单件尺寸与形态（原来只有这一项，不够）

      「人物」这一项**也必须按四件套写，缺一件算没交**（这是事实，不是意见）：
       · **人数**：一共几个人，谁是出镜者
       · **年龄外观**：目视区间（例 16–22 岁）＋ 是否像儿童。**只报外观，不下"能不能用"的结论**
       · **人脸特写次数**：全片给了几次"人脸占画面 1/3 以上"的镜头。0 次就写 0 次
         （B0006 实测：全片 0 次，只给侧脸和背影）
       · **正脸:侧脸:背影比例**：按镜头数算，例 0:7:21
       另记两项：**最大人脸占画面高度几成**（例 18%）、**有没有"对人做表情"的镜头**（有／无，几次）。
       这两项决定复刻时主角的正脸要不要给、给到什么程度，所以必须单独列出来，
       不许只藏在情绪弧的五通道表里。

    为什么必须这么写：观众感知的是「这块地有多少被占了」，不是「有几片叶子」。
     写「数十片」→ 下游会写成「40 到 50 片」→ 画出来地上一小堆，与「铺满整条廊」差一个数量级。

  3b）**冲突强度**（新增，单列一段，缺了算没交）

     · 有对比关系的片子（这边乱 vs 那边整、改造前 vs 改造后）：
       写 `A 侧 X% vs B 侧 <Y% 或 0 处>，差 Z 个百分点`
       X 取自本文件表 3 的占比，Z = |X − Y|。
     · **改造后那一侧不要直接测百分比。** 改造后常有暖光、木家具、陶盆，
       按颜色测会把暖光当成脏东西（实测 B0001 末帧暖灯一开，「褐色占比」从 0 跳到 13.5%，是误判）。
       改造后只判**有/无**：问题物还在不在，写「0 处」。
     · 占比只在**同机位、同光照**的两帧之间可比。跨光照比较必须注明
       「改造后开暖灯，光照变了，占比不可直接比，只判有/无」。
     · 没有对比关系的片子：写「无对比，冲突来自 <危险 / 失败 / 欲望 / 悬念 / 人物关系>」
     · **禁止只写类型不写强度。** 「是反差」不算，要写「差 25 个百分点」。

  4）首帧六要素（原五项 ＋ 新增第 6 项，缺一项算没交）
     受害物位置 / 威胁方向 / 距离 / 画面里有几个人 / 机位高度与是否固定 /
     **观众第一反应（三选一，禁止形容词）**
      写法固定成单独一行：`观众第一反应：必须马上处理`
      冒号后只许写一个选项，不许把三个并列写出来。

     第 6 项只能填这三个里的一个，填别的算没填：
       `必须马上处理`（不处理人看着难受）｜`可以忍但不好看`｜`看着舒服`

     填「必须马上处理」的，必须再补一句**依据**：画面上哪一处让正常人忍不住
     （例：烂纸箱泡在泥水里、一脚下去会滑、隔着屏幕都闻到味）。
     依据写不出来的，说明这个反应是编的，退回重判。

  5）情绪弧
     一句话写清原片情绪是什么、观众该有什么感觉。
     **这一句必须带「难受程度」的数字**，用 0–3 标「不处理会有多难受」：
       0 无所谓 / 1 有点在意 / 2 明显难受 / 3 看不下去
     例（示例，内容必须换成你这条片子）：「暴雨把走廊泡成一地烂叶，乱到看着**难受 3**、不收拾没法待 → 清干净、挂雨帘
         → 廊下干爽、暖灯亮着能坐下喝东西，最后松一口气」。
     只写「闷、脏、潮」这类**情绪名**不算，必须带程度数字，且在句子里说清是哪种程度。
     按五通道逐个查原片用了哪几个：
       ① 表情视线　② 身体动作与节奏　③ 环境（天气光线）　④ 声音　⑤ 镜头语言
     然后逐段给：情绪、强度（0 无 / 1 微 / 2 中 / 3 强）、载体

【文件四】03_整片拆解.md

  ★ 「结尾方案（人读版）」—— 放在逐段表之前，**不参与编号**，缺这一节算没交

    这一节是给人看的。不超过 400 字，不许放表格，必须回答五件事：

      · 最后几秒、几个镜头、每个镜头画面里是什么
      · 光怎么变：首帧到末帧是变亮还是变暗、色温怎么走（例：冷灰 → 暖黄，亮度 ×1.18）
      · 对照物还在不在：挡雨的片子，结尾必须还在下雨；隔音的必须还在响。
        对照物没了，「改造」这件事就没有证据，写清是本条怎么处理的
      · 有没有人在用：有就写第几秒、谁、用了什么；没有就写「缺口」。
        只陈述缺什么，**不建议补几秒**——补不补、补多长，由复刻那一段定
      · 这一段最容易做错什么（一句话，要具体到秒数和动作）

  后半段逐段表（段 / 起止秒 / 画面做了什么 / 景别·机位·运动 / 职责
  　　/ **状态变化（从什么变成什么）** / **动作数** / **位移**）
  ＋ 终局兑现链（开头问题 → 中间动作 → 终局状态 → 使用验证），
    并且**「终局状态」必须拆成两栏，缺一栏算没交**：

      · **根治项**：开头暴露的每一个问题，逐项写它在第几秒被解决。
        **开头问题数必须等于根治项数**，对不上就说明有漏，要在结论里写清漏了哪一项。
        （这一栏同时是「改造是否够量」的判据：根治项数少，观众就会觉得「浅浅收拾了一下」。）
      · **升华项**：开头没有、改造后新加的东西（挡雨结构、灯、绿植、家具、氛围）。
        逐项列出，并写清每一项解决了什么「根治解决不了」的需求。

      判定：只有根治、没有升华 → 结论必须写「只解决了脏，没有提升，观众不会有『变漂亮』的爽感」。
      有升华但没有根治 → 结论必须写「表面漂亮，核心问题还在」。

  「状态变化」这一列是给复刻抄的：换表面时，这一列必须一字不改地搬进设定书 4.5 节。
  「动作数」按"一次状态变化算一个动作"数，不是按手部步骤数。原片实测每镜 1–2 个。
  「位移」写是/否：人带着东西在空间里移动＝是。这一项决定下游要不要单独给 2 秒。
  「景别·机位·运动」写法同【文件三】1）逐镜表，三样缺一不可。

  ★「生成组划分表」——放在逐段表之后、终局兑现链之前，缺这节算没交

    这张表只回答一件事：**哪几段必须绑在同一次生成里，哪几条缝不许缝在外面。**
    逐段表是按「画面切在哪」切的；生成组是按「动作能不能切开」切的。两者不是一回事。
    现在全流程只有前者，所以组边界会被下游按预算算术决定，而不是按动作决定。

    **这一层不决定最终划几个盒。** 最终盒数由第⑤段按硬表区间定（成片 36–50 秒 → 4–5 盒）。
    这一层只交两样东西给第⑤段：① 每一组的「不可分」边界；② 哪几条边界是「禁切」。
    第⑤段装箱时可以合并相邻组，**但合并线不许跨过任何一个「禁切＝是」**。
    举例：44.4 秒的片子按动作划出 6 组、硬表要 4–5 盒 → 合并两条相邻组即可，
    只要那两条之间不是禁切。**组数多于盒数是正常的，不许为了凑盒数把连续动作切开。**

    | 组 | 起止秒 | 含第几段 | 镜数 | 本组边界为什么不能更早／更晚 | 组内有无连续动作（有→禁切） | 组时长 |

    四条硬规则：
    · **一组 ≤10 秒。** 不写 12、不写 15——15 秒是平台容量，不是模型能力。
      实测：失败的长盒全在 12–15 秒，成功的全在 8 秒内。
      10 秒是**上限不是目标**：能有 3 秒的组，就写 3 秒。
    · **下列连续动作必须在同一组**：起跳—落地、抬起—放下、掀开—盖上、抓住—拉起、
      开门—进入、踩断—陷落、递出—接住。判据是**前一段的尾帧就是后一段的首帧**。
      这两下分开生成，「基本是剪不出无缝衔接的」。
    · **组边界只能落在**：硬切、场景变化、人物进出画、时间省略。
      **时间点本身不新增组**——「这段 3 秒了，切一下吧」不算理由。
    · 某组超 10 秒且切不开 → 在表里标「超限」，并写明**这一组会丢什么**
      （例：会丢「掀板看水」那一下，因为它在 3.3 秒里是第三件事）。
      **不许静默压缩**——静默压缩的后果是成片里那一段只剩 0.5 秒。

  ★「静态大纲（生成用）」——**按组写，不是按段写**，缺这节算没交

    这一节是把上面所有的账翻回画面。下游拿它直接写提示词，不再重看片。
    没有这一节，下游只能从 360px 的联络表里猜机位和光，猜出来的东西和原片没关系。

    格式：一组一个小标题，组内一镜一段。每镜先一行参数，再一段白话。

      ### G02｜7.733–15.300｜7.6 秒｜含第 3–5 段

      1.6 秒／24mm／固定／机位高 1.4m／略仰 3°
      画面左缘是碎石路肩，前景有一段枯枝，虚化；背景是中景的浅黄木板房、门廊灯亮着、
      廊下停一辆自行车，轻度虚化。白色皮卡从画面左侧压过落叶驶入，车头朝右，停在草坪边；
      车厢里看得见手锯、撬棍、推车和几根木方。阴天漫射光，无直射，色温偏冷，地面无强阴影。

      5.1 秒／24mm／固定／同机位，不推不摇
      前景不变；背景木板房不动。驾驶位车门打开，绿衣灰帽的男人下车、绕到车尾、放下尾板，
      把油锯和铁锹拎下来堆在桥头碎石上，再推下独轮车。他最后停在画面中偏右，
      面朝桥、背对镜头，双手撑膝俯身看桥面。光不变。

      ……（组内其余镜同格式，一镜都不能省）

    每镜那段白话，必须**同时说清五件事**，缺一件这一镜不算写完：
      ① 机位与高度　② 前景是什么、虚不虚　③ 背景是什么、虚不虚
      ④ 主体从画面哪边进、在哪停下、最后什么姿态　⑤ 光从哪来、软硬、冷暖

    硬规定：
    · **禁用表格、禁用百分比、禁用「同上」「同前」「照旧」。**
      每一镜的五件事都要重写一遍，不许引用上一镜。这和单元卡「不写同上」是同一条纪律。
    · **每 30 秒约 600 字。** 写不下就是拆得不够细；写到 2000 字就是掺了废话。
    · **只写看得见的东西。** 施工工法、材料配比、人物内心一律不写。
      写「35mm 手持跟随，拍她腰臀以上，她从画面左侧入镜」；
      不写「她心里很着急」，也不写「混凝土按 1:2:3 配比」。
    · 这一节描述的是**原片怎么拍**，不是我们怎么拍，所以它不违反「不设计我们的片子」。

【文件五】04_交付自查表.md
（**给人看的**：下游不读它。它的作用是让你自己核一遍，不是给下游当输入。）

  这一份是你自己对自己交的账，不是给我看的总结。三节，缺一节算没交。

  · **一、硬字段逐项**：骨架三段 ＋ 对账四元组、问题物四件套、人物四件套、冲突强度、
    首帧六要素、情绪弧、终局兑现链、**生成组划分表、静态大纲**，
    每一项一行，写「值」和「过／不过」。
  · **二、这一轮新加的两节，逐条自检**（缺这一节算没交）：
      - 生成组：共几组？有几组 ≤10 秒？有没有标「超限」？超限那组写了会丢什么吗？
      - 静态大纲：覆盖了几组／几镜？有没有出现「同上」「同前」「照旧」？
        随机挑一段数一下字数，够不够每 30 秒 600 字？
  · **三、未核清单 ＋ 需要人来定的事**：照实写，不许用「待补」糊过去。

硬规则
════════════════════════════════════════

1. **模式 A**：只拆解。不评价、不改写、不设计、不写提示词。
   **模式 B**：要评价差距、要给「怎么追」，但同样不写提示词、不做分镜设计。

2. 看不到、听不清、拿不准的，一律标「未核」，不许猜。
   声音没听就写「声音未核」，不许写「无声音」。

3. 秒数按事件边界切，不按固定秒数硬切。
   写清采样精度（镜头中点帧 1 镜 1 张，还是 5 帧/秒，还是 0.2 秒一张）。

3b. **切点只有一个来源，镜数只有一个数。**
   ffmpeg 场景检测给的切点，和你人判的事件边界不一致时，**以事件边界为准**，
   并在逐段表下面写一句「场景检测 __ 处，人判 __ 处，差在 __ 秒，按人判」。
   `00_对标索引` 的镜数、`03_整片拆解` 的段数、平均镜头长度这三处**必须同源同数**，
   对不上算没交。反例（真实发生过）：B0009 同时存在「10 镜」「12 段」「44.42÷11＝4.04 秒」
   三个数，密度结论跟着漂。

4. 画面里有像儿童的人，必须在 00_对标索引.md 里明确标出来。

5. 文件权限，两种走法，不许含糊：
   能建目录、能存文件 → 目录自己建、文件自己写，最后报真实路径。
   不能 → 写清让我手动做什么：建哪个目录、每份产物存成什么文件名。
   两种都不许说"已创建"却什么都没落地。
   **但都不许先停下来问我一句「我可以建目录吗」——先动手试，试不了再写清单。**

6. 拆得越细越好。

7. **「占比」必须原样传下去，不许改写。**
   表面清单里的画面占比（X%），在后续设定书、制卡词、提示词里必须原样保留这个百分比，
   **不许改写成片数、件数、堆数、把数**。
   反例（真实发生过）：拆解写「落叶数十片」→ 中间过程稿抄「数十片」→ 制卡词写成
   「湿枫叶 40 到 50 片」→ 画出来地上一小堆。实测对标首帧落叶占画面 25.0%，成片只有 1.1%，
   差 23 倍。改写一次，量级就掉一到两个数量级，后面每一步都会忠实地照着错的量级执行。

8. **「程度」不许用形容词，只能用数或三选一。**
   禁止出现「很乱」「特别脏」「乱到极致」「一点点」「比较多」这类词充当结论。
   要么给占比、差值、项数、秒数，要么用三选一（观众反应）。
   形容词只能出现在「依据」里，不能出现在「判断」里。

五、模式 B｜成品 vs 对标：对比反馈
════════════════════════════════════════

只在给了两条视频时执行。**不交 02／03／04，只交 `05_对比反馈.md`。**
`检查_拆解.py` 会报「缺 02／03」——**那是预期的，不要补假文件。** 模式 B 的验收方式是第六节。

这一节只回答三件事，顺序不许换：**差在哪 → 为什么差 → 怎么追。**
每一件都要落到秒数或项数，不许写「感觉不对」「节奏偏快」。

## 1）读到的原文
同开场那段抽问单规定：六句一字不改抄回。抄不出、改写、只写「已阅读」＝这一版打回。

## 2）身份对账（先对齐口径，再谈差距）

| 项 | 对标 | 我方 | 差 |
|---|---|---|---|
| 时长 | | | |
| 画幅／帧率 | | | |
| 段数 | | | |
| 镜数 | | | |
| 平均镜头长度 | | | |
| 动作数合计 | | | |
| 位移次数 | | | |
| 人脸特写次数 | | | |
| 正脸:侧脸:背影 | | | |

采样精度两边都要写清。**两边抽帧规格不一致的，先说明差在哪，再比。**

## 3）逐镜对照表（主体，不许省行）

**不按段号对齐，按「职责」对齐。** 两边各自先按
`问题出现／第一反应／决定动手／连续修／再测试／这次没事／收尾`
归一次，同一职责放同一行；我方缺哪一拍写「我方：无」，多出来的写「我方：多出一拍」。

| 职责 | 对标·起止秒 | 我方·起止秒 | 秒数差 | 状态变化差 | 动作数差 | 景别·机位差 | 前景背景差 | 光差 | 差在哪个字上 |

最后一列「差在哪个字上」只写**一处**，必须是可改的具体东西。
写「我方踩断那一刀只给了 1.2 秒，原片 2.8 秒，脚没有真正陷进去」；
不写「节奏偏快」。

## 4）三处最大差距（只写三处，按「改这一处能补回多少观感」排序）

每处固定四行：

- **差在哪**：秒数 ＋ 具体动作 ＋ 我方缺什么
- **为什么差**：只能填四类之一——`规划`（组划错／单元划错）／`写法`（提示词没写清）／
  `模型`（能力不够）／`剪辑`（取用或顺序错）。四选一，不许写「综合原因」
- **怎么追**：一句可执行的话，写到「下一版第几段改成什么」
- **验证**：下一版用哪一项能看出追上了（取用率／段长／动作数／某镜是否出现）

## 5）模式 B 禁止做的事

- 不许把差距写成形容词，每一条都要有秒数或项数
- 不许一次列十条差距——列多了等于没排优先级
- 不许写提示词、不许改设定书、不许改分镜
- 不许因为自己片子做得差就说「这条对标不能抄」。差距是对齐问题，不是选源问题

## 6）未核与需要人定
同【文件一】第 0 节「事实边界」的写法。

## 7）模式 B 的落地顺序

1. 建目录：`<今天八位日期>_C####_<短名>\
   编号规则同第二节，扫 `*_C####_*` 取最大 +1。C 号与 B 号**分开计**，互不占用。
2. 落盘 `00_对比反馈.md`（上面 1–6 节）＋ `01_证据\`（两边各一张首帧、各一张末帧）。
3. 报三样：路径、字数、三处最大差距各一句。

════════════════════════════════════════
六、模式 B 怎么验收（不用 Pipeline）
