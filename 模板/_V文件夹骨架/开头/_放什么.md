# 开头\ 放什么

**谁写**：第③段（开头 0–T 秒）
**谁读**：第⑤段（生产会读 开头交接，并按交接里指的路径去取共用卡与 U01）

> 本步还要写两样，但**不放在 开头\ 里**：`共用卡制卡词.md` 放版本根目录，`U01.md` 放 `单元\`。
> 因为这两份是全片程序要读的文件，路径写错第⑤段就读不到。

| 文件 | 内容 | 必备 |
|---|---|---|
| `开头方案_有效.md` | 逐段表（段/秒/画面/情绪名/强度/载体/旁白/字幕分组）＋ 首末态 ＋ T 秒末态十项键值 | 是 |
| `开头交接.md` | T 值、T 秒末态十项键值、旁白逐字与时间、C0 锚点、未决项、媒体状态 | 是 |
| `共用卡制卡词.md`（**放版本根目录，不放本目录**） | 全片共用卡：每张参考卡的完整中文制卡词、父图、输出文件名与参数 | 是 |
| `U01.md`（**放 单元\，不放本目录**） | 开头段单元卡：标题 ＋ 五行头部 ＋ 唯一「## 拼好的完整正文」text 块 | 是 |
| `任务记录.md` | 来源、纠正、版本 | 是 |

**媒体状态**：未生成就写「未生成」。不许写「已接受」。
