# 分镜\ 放什么

**谁写**：第④段（小分镜 T 秒–结尾）
**谁读**：第⑤段（生产会读 分镜交接 和 后段小分镜_有效）

| 文件 | 内容 | 必备 |
|---|---|---|
| `后段小分镜_有效.md` | 每段七栏 ＋ 完整旁白表 ＋ 情绪节拍表续段 | 是 |
| `分镜交接.md` | T 起点、结束秒、情绪表续到哪一段、未决项、三处闭环核对 | 是 |
| `改动影响清单.md` | 对着设定书逐段判断：直接照抄 / 只换表面 / 必须重写 | 是 |

**七栏**：对标实际情况｜新片起点→按秒动作→终点＋机位｜要看懂什么｜人物情绪｜不能丢｜风险与依据｜当前可验层

**人物情绪栏格式**：触发 → 情绪 → 强度 → 载体
例：看见水已漫到地毯 → 急 → 2 → ②身体（快步不跑）+ ④声音（脚步踩水）
