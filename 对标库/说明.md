# 对标库

拆解过的对标视频存在这里。一条一个文件夹，编号四位数字，永不复用。

```
对标库\
└─ B0001_原片短名\
   ├─ 00_对标索引.md
   ├─ 02_开头拆解.md
   ├─ 03_整片拆解.md
   └─ 01_原片证据\
      ├─ first_frame-001.jpg     ← 必须是 0.000 秒这一帧，名字不能改
      ├─ overview-001..N.jpg
      └─ opening-001..N.jpg
```

第一次用是空的，正常。

怎么建、每个文件里写什么，看 `指令\1_拆解.txt`，或者点开 `流程导图.html` 的「① 拆解」。
