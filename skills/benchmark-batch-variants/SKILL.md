# 第二部分：先拆透（这是所有判定的基础）

拆不透，后面全是猜。拆解要按下面三张固定表，字段不许省。

## 2.1 逐镜表（四要素）

| 段 | 起止秒 | 画面一句话 | 环节 |
|---|---|---|---|

"画面一句话"必须同时写清四件事，少一件这条就算没拆：**谁 + 在干什么 + 东西什么状态 + 景别**。

例（拆解_02 第 1 段）：一辆红色拖拉机（白T司机）从路远端朝镜头开来，前景路中是一个积着粉褐色水的椭圆坑；1.6s 左前轮压进坑，泥水溅起。固定低机位，远景→全景

## 2.2 七段环节骨架（固定分类，不许自己起名）

改造/修复类一律按这七段归类，没有的写"无"：

| 编号 | 环节 | 判定方法 |
|---|---|---|
| 1 | 问题出现 | 从第 0 秒到"坏事完成"（车压进坑、雨打到东西上）为止 |
| 2 | 第一反应 | 出事之后、决定之前：看一眼、愣一下、走近 |
| 3 | 决定动手 | 打电话、叫人、拿工具、走到位置 |
| 4 | 连续修 | 第一次接触要修的东西，到修完为止 |
| 5 | 再测试 | 修好之后，同一个威胁再来一次 |
| 6 | 这次没事 | 再测试之后，证明这次扛住了 |
| 7 | 收尾 | 空镜、合影、竖拇指 |

**修坑 8 条实测**：1 占 0–5 秒，2 占 4–5 秒，3 占 4–5 秒，4 占 35–59 秒，**5 和 6 全部是"无"**，7 占 2–4 秒。八条都省掉了"再测试＋这次没事"。

这条对我们很重要：它说明 5、6 两段不是必需的。但我们自己 70 万那条有这两段，所以**自己不删，对标上没有也不许当成缺点**。

## 2.3 表面清单（十项，一项不许缺）

| 项 | 写什么 | 例（拆解_01） |
|---|---|---|
| 地点 | 场地类型、路面/地面材质、两侧是什么、有无国别可辨 | 乡间红土路，两侧绿色农田、树和土堆碎石，看不出国别 |
| 问题物的大小形状 | 占画面多少、深度、边缘状态 | 近方形坑，宽约占路面三分之一，深看不清，外圈深色湿泥 |
| 天气 | 晴/阴/雨、光线、地面干湿 | 白天多云，部分蓝天，路面潮湿 |
| 人物 | 几个人、年龄段、各自身份、谁和谁重复 | 3 人，都是 10–14 岁儿童/少年，绿T男孩既摔车也参与修 |
| 穿着 | 逐人写颜色＋品类＋鞋 | 薄荷绿T＋破洞牛仔＋凉鞋 |
| 工具 | 逐件写，含"压坑道具"（如车）和"修的道具" | 自行车、橙色塑料盆、短柄锄头、扁平抹平工具 |
| 材料 | 逐样写，含"看不清是什么"的要标出来 | 大石块、碎石、白袋灰白粉末（是不是水泥看不清）、土 |
| 修法 | 用箭头写工序，一步一箭头 | 舀积水→填大石块→铺碎石→倒灰粉翻拌→锄头铺平拍实→手工抹平 |
| 画面文字 | 字幕、贴字、衣服上的字 | 无字幕；只有衣服上的 CK 字样 |
| 声音 | 口播、环境声、动作声、BGM | 未核 |

## 2.4 开头段长度 T（变量，不许套默认值）

**T 不是常数。** 原片有的 3 秒、有的 5 秒、有的十几秒，取决于它什么时候开始动手。定 T 三条规则，按顺序用：

1. **主规则**：T ＝ 原片里"人第一次接触要处理的东西"的时刻，取到那一段动作结束。
   - 修坑 01 开舀 13 秒 → T=13；修坑 02 开刨 16 秒 → T=16；修坑 06 开工 22 秒 → T=22
   - 收衣片伸手抓夹 2.2 秒、动作到 2.6 结束 → T=2.6
2. **没有"动手"段**：T ＝ 第一段有效动作结束的时刻，不是总时长。
3. **比例校验**：T 应占成片总时长 12%–18%。超出就换源，或单独写明为什么例外。

T 一旦定下写进版本设定书，下游三段一律引用，不许各自重算。

## 2.5 情绪弧（必拆，不许省）

情绪是结构的一部分，不是装饰。先写一句话：**这条原片的情绪是什么，观众看完该有什么感觉。**

母版例：看着东西正要坏、拦不住的那种着急；落点是"抢到了"的轻微释然。没有愤怒、没有抱怨、没有表演。

然后按**五个通道**逐一检查原片用了哪几个：

| 通道 | 查什么 |
|---|---|
| ① 表情与视线 | 有没有脸部表演？持续几秒？还是只有一闪 |
| ② 身体动作与节奏 | 快走还是跑、肩背姿态、动作干脆还是犹豫 |
| ③ 环境（天气、光线） | 天色、光线方向、雨雪风、地面干湿 |
| ④ 声音 | 雨声疏密、脚步、动作声、有无配乐 |
| ⑤ 镜头语言 | 全景看局面还是特写看结果、切点节奏 |

**修坑实证**：8 条修坑片的人物都是平静干活，没有表情戏，结尾竖拇指。高低播放的差别不在表情。所以**改造/修复类的情绪大头在②身体节奏和③环境，不在脸**。

**强度标尺**（统一口径，不许自创）：0 无｜1 微（停一下、看一眼）｜2 中（加快动作、皱眉一次）｜3 强（跑、喊、摔东西）。改造类原则上不上 3。

**禁止**：写"他看起来很着急"这类无法生成的抽象描述；用对白或旁白解释情绪；加叹气、摊手、摇头等原片没有的表演动作。

## 2.6 首帧五要素

第 0.0 秒这一格，单独写清五件事：

1. 受害物在不在画面里、在哪个位置（前景/中景/画外）
2. 威胁在不在画面里、朝哪个方向来（正对镜头/侧面/尚未出现）
3. 威胁离受害物还有多远/多久
4. 画面里有没有人、几个人
5. 机位高度、是否固定、景别

例（拆解_06，高播放）：摩托在远处正对镜头骑来，坑在前景，两者距离约 2 秒。

# 第三部分：变 / 不变 判定表（本 skill 的核心）

分三层。每一层都给"怎么算相同、怎么算不同"，判定时逐条写结论，不许写"基本一致"。

## 3.1 锁死层（13 项，每版必须完全一样）

| # | 维度 | 判定"相同"的标准 | 越界的例子 |
|---|---|---|---|
| L1 | 造的东西 / 修的对象 | 能用同一句话说出是同一样东西 | 「四柱白顶凉棚」→「木平台餐椅凉棚」＝不同，越界 |
| L2 | 步骤清单与顺序 | 一步一行，步数差 ≤1，顺序完全一致 | 少一步、多一步、换顺序 ＝ 越界 |
| L3 | 每一步的动作 | 动词一致：砸、舀、抹、拧 | 「砸」换成「钉」＝越界（锤子换棒子可以，砸不能换） |
| L4 | 工具种类 | 同一功能类 | 锄头→铁锹 可；锄头→电钻 不可 |
| L5 | 材料种类 | 同一功能类 | 石块→碎砖 可；石块→水泥浇筑 不可 |
| L6 | 出事方式 | 机制一致：谁从哪来、怎么碰上 | 正面开来→前轮压进 可；从侧面冲进来 不可 |
| L7 | 结尾验证方式 | 同一个验证手段 | 竖拇指→竖拇指；空镜→空镜。改成"再测试一次"＝越界 |
| L8 | 人物 | 同一个人（Alex），不换 | 换成邻居／换性别／换年龄段 ＝ 越界 |
| L9 | 场面规模 | 出镜人数上限不变（修坑是 2–4 人） | 加一队人 ＝ 越界 |
| L10 | 总时长 | 母版 ±5 秒 | 95 秒改成 60 秒 ＝ 越界 |
| L11 | 关键时间点 | 出事秒、开工秒、结尾秒，各 ±1 秒 | 出事从 2 秒挪到 6 秒 ＝ 越界 |
| L12 | 机位策略 | 机位数、是否固定、高度层级不变 | 固定机位改成手持跟拍 ＝ 越界 |
| L13 | 情绪弧 | 每段的情绪、强度、五通道分配与母版一致 | 「着急」改成「生气」＝越界；把情绪从②身体搬到①表情＝越界 |

> L2 与"刀数"无关。修坑 8 条步骤完全一样，刀数却从 16 到 27、时长 55–78 秒，说明**照抄的是步骤，不是逐刀**。刀数、每刀几秒属于可换层（C4）。

> **L10 是硬锁，没有例外。** 母版 29 秒就做 29 秒。不许以"频道成片都 80–95 秒""经验时长"为由放大——本规范里没有这条规则。等比缩放不改变任何比例（T ÷ 总时长拉伸前后同一个数），所以"拉长以凑 12%–18%"在数学上不成立。母版时长与目标差太远，属选源问题，换源，不要拉伸。

> L11 与 L13 会互相牵连：调 L11 的时间点，可能挤掉某个情绪载体（例如时间提前后没空皱眉）。**这类连带变化必须写在改动单的"情绪是否要跟着调"一栏**，否则下游照抄原情绪表就会打架。

## 3.2 可换层（8 项，每版全换且互不相同）

| # | 维度 | 换法 | 限制 |
|---|---|---|---|
| C1 | 受害物 | 换同一类里的一件（怕雨的：坐垫→纸箱→地毯，都是怕雨的家居物） | 必须同类。坐垫→电钻 不行，电钻不"怕雨淋坏"这个语义 |
| C2 | 地点细节 | 院子/墙面/植物/地面/朝向换掉 | 不能换掉场地类型（独栋户外不能换成公寓阳台） |
| C3 | 天气细节 | 晴天/阴天/雨后/阵雨、光线方向 | 不能换掉"外部条件突变"这个机制 |
| C4 | 每步怎么拍、几刀、几秒 | 按能生成、好看为准自由安排 | 不许删掉整步；不许整段改成蒙太奇跳过 |
| C5 | 人物穿着 | 颜色、款式、材质换掉 | 不写颜色文字，只引 RC01 身份图（写了会漂） |
| C6 | 道具颜色与外观 | 换色、换款式、换旧新程度 | 不改种类（改种类是 L4） |
| C7 | 数量细节 | 帮忙的人 2–3 个、道具几个 | 上限受 L9 约束；不许加"无关路人"（见 D9） |
| C8 | 画外细节 | 背景里的车、树、远处的房子 | 不许抢主体注意力，不许引入第二条故事线 |

## 3.3 可调层（子维度，每版只占一个）

**关键：可调单元不是"整个环节"，而是环节下面的具体子维度。** 只写到"环节"这一层，四个版本全会挤在"问题出现"上撞车——这是上一版最大的粒度错误。

下表 A 组来自修坑 4 对的实证，有方向；B、C 组没有外部证据，只能靠自己的母版。

### A 组｜前 20 秒（有实证，优先用）

| # | 子维度 | 高播放的做法 | 低播放的做法 | 证据 |
|---|---|---|---|---|
| A1 | 首帧关系：威胁是否正对镜头来、受害物是否在前景 | 第 0 秒：车在远处正对镜头开来，坑在前景 | 空坑（05、08）；车从侧面突然入画（07） | 4/4 高片一致；低片 3/4 不同 |
| A2 | 出事时点 | 1.6–2 秒才碰上 | 1 秒内就碰上 | 4/4 |
| A3 | 受害者数量 | 1 个，且本人就是后面动手的人 | 07 三次受害；05 前 10 秒在捡果子（后来再没出现） | 4/4 高片 |
| A4 | 问题段冗余（无关的人/车） | 无 | 08 有 4 拨车和人 | 4/4 |
| A5 | 开工时点 | A 22 / B 13 / C 15 / D 16 秒 | A 29 / B 19 / C 26 / D 17 秒 | 每一对都是高的先开工；D 组基本持平 |

A 组内部还有一层关系要注意：**A1–A4 全部落在"问题出现"这一段的四秒里**。也就是说前 20 秒的差距，几乎全由这四秒决定。0051 说的"删冗余"，在修坑里指的就是这一段。

### B 组｜中段（实证与直觉相反，别乱动）

| # | 子维度 | 实证 | 结论 |
|---|---|---|---|
| B1 | 修的时长 | 高的修 32–59 秒，低的修 32–44 秒。**高片的中段更长** | 中段不是越短越好。不要压缩 |
| B2 | 步骤完整性 | 8 条步骤一步不少 | 不能为了节奏删步骤（L2 兜底） |

# 第四部分：版本怎么排

## 4.1 先算上限

```text
可调子维度数 = A 组可用的 + B/C 组确有疑问的
本批最多版本数 = 可调子维度数 + 1     （+1 是最前面的对照版）
```

修坑这套骨架，A 组 5 个 + C 组 1 个 = 6，所以最多 7 版。要 4 条，够。

如果可调子维度只有 2 个，就只能出 3 条。**不许为了凑数把一个子维度拆成两个，也不许让两版占同一子维度。**

## 4.2 V1 是对照版

锁死层全抄、可换层全换、**可调层一处不动**。它测的是"这个骨架在我们频道能不能复现"。这条不行，后面几条全不用做。

## 4.3 V2 起，按优先级分配

| 顺序 | 子维度 | 为什么排这个位置 |
|---|---|---|
| V2 | A1 首帧关系 | 决定第一眼划不划走，占成败七成 |
| V3 | A2 出事时点 | 直接决定"有没有等待感" |
| V4 | A3 受害者数量 | 决定动机集中度 |
| V5 | A4 问题段冗余 | 删减类，风险最低 |
| V6 | A5 开工时点 | 中段入口，影响完播 |
| V7 | C1 结尾验证 | 只有自己的母版支持，最后试 |

**一版只占一行。** 想同时调 A1 和 A2，就再加一版，不要合并。

## 4.4 版本差异矩阵（一批一张）

| 版本 | 一句话差异 | 占的子维度 | 调法 | 本版只测什么 | 预期 |

# 第五部分：五道硬判定

每版逐条写"通过／不通过"，不通过就退回，不许带病往下。

| # | 判定 | 怎么判 | 不通过怎么办 |
|---|---|---|---|
| J1 | 没越界 | 锁死层 13 项逐项对照母版，任一项不同即 FAIL | 改回母版，或换对标源 |
| J2 | 因果三问全"是" | ①开头被威胁的东西＝正片要保护的那件？②正片造的东西正好对付这个威胁？③结尾验证的是同一威胁打在同一件东西上、这次没事？ | 改表面或改开场，不许改骨架 |
| J3 | 不撞车 | 两版占同一子维度即 FAIL | 改掉一个，或减条数 |
| J4 | 表面不雷同 | 两版在 C1 受害物、C2 地点、C3 天气、C5 穿着 四项上，任一项相同即 FAIL | 换掉那一项 |
| J5 | 不超限 | 版本数 ≤ 可调子维度数 + 1 | 减条数或换源 |
| J6 | 情绪一致 | 每段情绪名、强度、五通道分配与母版一致；改时间点导致的连带调整已写明 | 改回母版情绪弧，或在改动单里补记连带变化 |

## 5.1 三条口诀（人不用记表，记这三句）

1. 观众说得出「他这次做的是另一样东西」→ 换过头了（撞了 L1）。
2. 观众说得出「他这次少了一步／多了一步」→ 换过头了（撞了 L2）。
3. 两个版本并排看，说不出"差在哪" → 撞车了（撞了 J3）。
4. 看完觉得"假""演"→ 情绪分配错了（多半是把情绪从②身体搬到了①表情，撞了 L13）。

# 第七部分：发布后归因

台账第 2 张表每版一行，多填：母版编号、占的子维度、调法。

- 被调那段变好、其余没变差 → 保留，母版版本 +1
- 变差 → 退回，换调法再试
- 同一调法连续 2 条变差 → 记"无效"
- 判断只拿**发布头 24 小时**的数和母版同期比；之后会自然下降，不可比
- 一个调法至少看 2 条再下结论

# 第九部分：不做的事
