# 用量与工法：写每一刀时必须过的两道核对

> 建立日期：2026-11-01（B0018 V01 第④段六处工法不成立之后加的）
> 解决什么：整条链上所有闸门都只量**形状**（刀数、秒数、动作数、密度、景别），没有一条量**物理**（用了多少料、这个做法成不成立）。
> 结果：一份"看板 100% 全绿、体检通过、退出码 0"的分镜，里面可以同时存在"一车砂浆铺满五米路""把树根压进土里就算除根""在碎石里点几个垫块找平"。
> **本文件不是建议，是每一刀的必填项。**

---

## 一、用量核对：三条公式，一个都不许跳

| 量 | 公式 | 常见错法 |
|---|---|---|
| **体积料**（碎石、砂、砂浆、混凝土） | `面积 × 厚度 = 体积`，再除 `单车/单袋容量` | 写"倒一车铺满整条"，不除容量 |
| **块料**（砖、板、瓦、草皮） | `面积 × 块/㎡ = 块数` | 拍一个"约 40 块"，不乘 |
| **线性料**（木缘、栏杆、砖缘、管线） | `长度 ÷ 单件长度 = 件数` | 写"两侧各砌一道"，不除件数 |

**参考容量（现场常见值，估不准就按这个）**

| 项 | 值 |
|---|---|
| 独轮车 | 约 0.05–0.06 m³（砂约 80 kg） |
| 25 kg 袋装碎石 | 约 0.015 m³／袋 |
| 标准砖 200×100×50 mm | 平铺约 50 块/㎡；立起砌缘每米约 5 块 |
| 碎石基层（人行） | 厚 5–10 cm |
| 砂垫层 | 厚 3 cm |

**判据**：这一刀的用量 ÷ 上一刀留下的量，或 这一刀的用量 ÷ 画面里给出的料，**小于 0.9 就是不够**。不够只有两条路：加料（写进起手状态）、加刀（要 ② 点头）。

【例】B0018 V01：路径 5.0×0.9＝4.5 ㎡，砂垫层 3 cm＝0.135 m³；一车 0.05 m³ 只够 1.8 ㎡，整条要 **三车**。v1 只写了一车 → 剩下 3 米凭空有砂。

## 二、工法校验：五条，写完每一刀扫一遍

### 1. 工序名 ↔ 动作，必须对得上

工序名取自 `19_工序词表.md`，但**取了名字不等于动作对**。

- ✗ 工序写「铲除」，动作写「夯实」——夯实是「做基层」的活
- ✗ 工序写「自流平」，实际铺的是砂垫层——自流平是另一种材料
- 判据：把工序名的"一句话定义"念一遍，动作能不能被这句话覆盖？不能就是名实不符，报冲突。

### 2. 换材料必须重算工法

复刻片的动作文字通常是从对标**结构位置**映射来的（"这一段在做承重底"→"我们这一段也做承重底"）。**换了物件，工法常常跟着变**：

| 对标做什么 | 换了材料后不能照搬什么 |
|---|---|
| 木结构骨架（钉、拧、卡） | 换成碎石基层后不是"固定构件"，是"分层压实" |
| 混凝土浇筑 | 换成砂垫层后不是"浇"，是"刮平"；也没有"等它凝" |
| 装栏杆（附属物，最后装） | 换成结构性边缘约束时**必须先装**，砖靠着它铺 |

**判据**：这一刀的做法，能不能指到一条第一手来源（厂家说明、施工者记录、标准做法）？指不到（只能指回"对标那一段是这么干的"）→ 标「工法未校准」，不许当已确认。

### 3. 顺序约束：结构性构件先于面层

- 边缘约束（木缘、路缘石）**在铺面之前**装，面层靠着它铺
- 基层压实 **在** 垫层之前
- 垫层刮平 **在** 铺面之前
- **收尾工序不能省**：铺砖要扫缝砂、铺草要压边、刷漆要等干

装饰性/挡土性的构件（花圃挡土砖缘、挂花篮）可以在面层之后做——但**必须在正文里写明它不承重**，否则读起来就是"结构件装晚了"。

### 4. 根因必须被真正去掉

- 顶起面层的树根：**剁断挖出**，不是压进土里（压进去还会长）
- 掏空的基层：**换掉**，不是盖上
- 松动的旧层：**起走**，不是补一块

判据：这一刀做完，**明年还会不会以同样的方式坏**？会 → 这一刀没解决根因。

### 5. 湿作业的时序

湿砂浆／混凝土铺完要等凝；砂垫层是干的、铺完就能上人。**同一段里不能既写"湿料刚铺"又写"人已经走上去"。**

## 三、写每一刀时的两行（模板）

在「下游／消费」两行下面再加两行：

```
用量：这一刀处理掉／放上去多少（米／㎡／块／升／车）
够不够：上一刀留下的 ____ ÷ 这一刀需要的 ____ ＝ ____（＜0.9 就报）
```

工法存疑时再加一行：

```
工法：依据 ____（第一手来源）／未校准
```

## 四、什么算"工法不成立"，怎么处理

| 情况 | 处理 |
|---|---|
| 工序名与动作对不上 | 改动作或改工序名，二选一，登记 |
| 换材料后做法照搬 | 按真实工法重写这一刀的动作描述 |
| 用量不够 | 加料（写进起手状态）或加刀（要 ② 点头） |
| 顺序反了 | 改描述（写明它不承重）或调刀序（要 ② 点头） |
| 根因没去掉 | 改动作 |

**改的时候形状四项一律不动**：刀号、成片秒、素材秒、动作数、景别。
改完在交接里登记「工法修正 W1／W2…」，写清"原、现、为什么原的不成立、秒数动没动"。
