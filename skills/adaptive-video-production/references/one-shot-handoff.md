# 一次性交付与跨对话协议

用于用户拿小分镜、前5秒方案持续讨论，最后要求“一次给齐生产单元、参考图和提示词”的项目。**一批文本一次交齐**不等于一批图片/视频同时付费生成；有真实缺口时完整说明局部阻塞，其他线继续。以用户已确认的现有唯一项目台账为准，不为协议再造第二本进度账。

## 1. 从讨论到交付：先锁事实，再分工

讨论期间保留原分镜、前5秒、不改的终局和用户最新纠正；不让过期版本参与当前生产。交付口令出现时，先把当前版本冻结成一份 [项目快照](../templates/project-snapshot.md)（它的 R 号就是本批修订号）。快照写入来源文件与版本、已确认事项、未决定事项、取舍原因、本批单元和图片职责；渠道参数只引用 SKILL.md；台账记录这个 R 号和待制/已有图片的实际状态。新决定覆盖旧说法时指出具体取代关系；未知项仅阻塞依赖它的提交，不以猜测填齐。

单对话可直接写完整包。并行时仅一位总控登记共享布局、分镜映射、有效图片版本；工作对话或写词子任务收到**快照全文＋自己完整单元卡＋相关文件实际路径/版本＋可改范围**（不给历史对话，见 [文件驱动生产](file-driven-production.md)），负责具体生图/视频正文，不重定故事、总图或他人单元。共享图片只指定一位作者；总控在实际提交前核对工作回传，采用变更只刷新受影响卡。用户不负责给多个对话重复讲背景。

## 2. “一次给齐”交付清单

按任务规模合在一个文件或聊天里，跨对话才拆卡；正文无占位符。可先给一句用户能直接看懂的下一步，其余保留为可复制生产内容。

1. **当前生产总图**：`N小分镜/前5秒 → U生成单元 → 必需已有图或(父图→PI完整生图词→待制图) → PV完整视频词 → V候选视频`。每条线说明为何合并/跳过、成片需看见什么、推荐生成时长与可剪目标；硬切与真正等待前段帧分清。
2. **共享资产表**：稳定ID@版本、绝对路径或“未生成的计划路径”、来源、已采用/待制/仅候选、负责对象、服务单元；不把文件存在写成用户接受。
3. **逐单元操作卡**：按 [单元卡](../templates/production-unit-card.md) 给实际上传顺序及每张图唯一职责/不借的内容；空间锚点和合法状态、人物/材料来处、镜头和音频、工具设置、可复制的全文正文、输出名、能否现在提交与唯一缺口。生参考图时列出真实父图和完整 PI 词，数量不超过 SKILL.md“渠道参数”表的上限。已有的图够用就写“无生图任务”。视频上传张数和时长同样以那张表为准，时长按动作需要来定。
4. **结果与变更入口**：用户生成后回报实际文件/版本、可剪内容、硬穿帮或音频问题。模型看过才写“AI已看”；用户说可用就记用户接受。下一轮只修改受影响单元和共享引用。

不能访问全体有效文件或用户只要求一个测试单元时，诚实标为“局部样品”，不假称全套已给齐。待制图尚无结果时：只要它在 `共用卡制卡词.md` 里有对应 RC 任务、输出名与下游引用逐字一致，下游视频照常按内容完整性和用户授权定状态（程序会自动等上游图）；没有上游任务或路径不确定，才写 `生产状态：草稿` 并列缺口。别把“图生成提示词已写”当“图已存在”，也别把“定稿”当“已生成”。落盘格式见 [交给自动生产程序](auto-production-table.md)。

## 3. 空间合同

凡是涉及安装、拆改、换机位、人物/宠物路线或终局功能的单元，都按 SKILL.md 第 5 步写四行：锚点、关系、状态、证据视点，写在单元卡上。只写当前确有风险的关系，不用把所有建筑都量一遍。逐张**打开实际图**，核对显眼的完成态、几何和内外关系；一张参考卡的多视图并不自动是可执行时间线。冲突明显时先减图/裁合适视图/补局部同空间图；缺图要列为具体缺口，不能把“文字让模型忽略一半图片”当可靠控制。照片看不到的支撑/施工安全不能由提示词宣称已经工程认证。

## 4. 提交前一次性自检与失败归因

总控只核五个可操作的问题，不增加日常审批准入：

1. 每个保留的小分镜/情绪/终局落到了一个U，删除或合并有可见理由；没有“一秒动作硬拖十五秒”。
2. 每张实际要上传的图真实存在、版本一致、职责不冲突；待制图PI父图真实存在且不超过渠道数量；画面矛盾不靠长串禁令掩盖。
3. 高风险单元跨镜头仍是同一空间、同一物件、合法施工阶段；人和材料有来源与接触；需要的功能视点真的能证明承诺。
4. 每张卡的上传、模式、时长、完整生图/视频词、声音、候选命名、提交状态齐备；不以“见上文/按总图”替代可复制正文。
5. 分工回传带本批修订号和输入版本。共享变更由总控登记，其他已有效的支线不返工；新对话开始/恢复/提交时只重读相关最新项。

出现失败，先分：**目标错误**（故事/功能本身）、**输入冲突**（图像不支持/状态超前）、**单元超载**（时长与镜头/动作）、**提示词遗漏**（有正确输入却未写关键关系）、**工具控制不足**（同图同词多次仍失真）、**后期声音/小瑕疵**。先用真实结果定位最早一层；不把所有故障都归咎于“提示词不够长”。可取的片段保留，重抽停止条件按现有规则。
