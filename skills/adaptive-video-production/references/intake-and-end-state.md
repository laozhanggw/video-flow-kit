# 输入与终局审核

先区分已核验事实、基于材料的推断、待验证假设。不要用“看起来真实”“观众会喜欢”替代证据。

## 全片合同

```text
目标观众：
真实问题：
停留理由：
观众等待的结果：
结尾必须兑现：
本轮唯一验证变量：
失败会是什么：
```

## 终局倒推

回答：人物/宠物最后如何使用空间或道具；这个动作需要哪些现实条件；开头暴露什么问题；中间哪个动作解决它；结尾哪个画面验证它；是否存在空间、动线、承重、排水、物业或安全漏洞。

核心功能没有解决动作和验证画面时，先处理该缺口，相关分支不进入可提交提示词阶段；不因此阻塞有充分输入且不受影响的独立工作。

将逻辑落实为可制作的最终使用画面：坐几个人、桌面承载什么、主要物件在哪里、通道是否留出。文字“舒服漂亮”不等于布局已定。多阶段空间制作继续读 [全片状态规划](state-planning.md)；只有冲突涉及的分支暂停，已有确认不重新做一轮全片审查。
