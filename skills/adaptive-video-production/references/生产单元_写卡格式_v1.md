# 生产单元写卡格式 v1（图片提示词 + 视频提示词）

**用途**：AI 写 `共用卡制卡词.md` 和 `单元\U0N.md` 时的唯一格式依据；也是人工验收的对照表。
**配套**：读取规则见 [单元卡_读取规则_v1](单元卡_读取规则_v1.md)；可直接粘贴的指令见 `指令\5B_写卡格式_通用.txt`。
**只读校验**：`python "{{ROOT}}/tools/Pipeline.py" 查 单元 --版本 "<本版本目录>"`，不花积分、不改文件。卡格式已并入总闸门，不要直接调子脚本。
**日期**：2026-11-01。依据 `import_project.py` 实际解析逻辑逐条反推，不是凭印象。

---

## 0. 一句话

**机器只读「头部字段 + 一个代码块」，其余全是给人看的。**

- 头部字段错一个字 → 整张卡**不导入**（日志里能看到）。
- 路径多一个括号注解 → 这条视频**静默跳过**，界面仍显示「完成」（2026-11-01 事故）。
- 所以：**头部当代码写，正文当文章写，两者不混。**

## 1. 三个文件，各管一段

| 文件 | 放什么 | 一条 = 什么 |
|---|---|---|
| `共用卡制卡词.md` | 全部图片任务 | 一张图 |
| `单元\U01.md` `U02.md`… | 每条视频一个文件 | 一段视频 |
| `说明\*.md` | 分析、依据、验收、版本记录 | 程序不读，随便写 |

- `单元\` 里**只放 U*.md**，放别的每次导入多一条「不导入」。
- 文件名（去 `.md`）就是任务编号，只能是字母数字下划线连字符。
- 全部 UTF-8。

## 2. 图片卡（`共用卡制卡词.md`）

### 2.1 骨架（逐字照这个结构）

````markdown
## RC02｜门前台阶空间参考

生产状态：定稿
父图：无
输出：生成\RC02_门前台阶空间参考_v01.png｜GPT Image 2.5 Flare｜3:2｜2K｜Medium

```text
（图片提示词正文，五段，见 2.3）
```
````

带父图的：

```markdown
## RC05｜阶段S1拆除后

生产状态：定稿
父图：项目文件夹\生成\RC02_门前台阶空间参考_v01.png
输出：生成\RC05_阶段S1拆除后_v01.png｜GPT Image 2.5 Flare｜3:2｜2K｜Medium
```

### 2.2 四个字段

| 字段 | 必须写成 | 硬规则 |
|---|---|---|
| 标题 | `## RC02｜中文名称` | 编号必须字母开头；`## ` 后第一段英文数字就是编号，所以编号后要跟 `｜` 或空格 |
| 生产状态 | `生产状态：定稿` | 只有「定稿／草稿」两种。含「暂缓」「不可提交」会被当草稿 |
| 父图 | `父图：无` 或 `父图：路径` | 纯文字生图必须写 `父图：无`，不能空着。多张用 `｜` 分隔，**从左到右就是上传顺序** |
| 输出 | `输出：生成\RC05_阶段S1拆除后_v01.png｜模型｜比例｜清晰度｜画质档` | 第一段是文件名，必须 `生成\` 开头、`_vNN.png` 结尾；版本号从这里取 |

**父图这一栏的括号会被程序整段删掉**（`场景(2).png` 会变成 `场景.png`）。所以：**文件名里不许出现括号**，注解写进正文或 `说明\`。

### 2.3 图片提示词正文：五段，顺序固定

代码块里是给网站模型读的连续中文。**不写 `#` 标题、不写 `1. 2. 3.` 编号列表**（模型会把它们当画面内容），五段各写成自然段，段间空一行。

| 段 | 写什么 | 反例 |
|---|---|---|
| ① 用途与视图安排 | 这张卡给哪几条视频用；几个视图、各是什么角度与距离；明确「同一时刻、只是换角度看，不是动作先后」 | 只写"生成参考图" |
| ② 固定条件 | 必须一致的空间形制、材质、颜色、比例、尺寸、光线 | 写成氛围描写（"温馨的午后"） |
| ③ 当前状态 | 这个阶段**已有什么、尚无什么** | 阶段卡不写"尚无"，模型会提前把成品画上 |
| ④ 画幅与标签 | 比例、每视图占比、留白处标简短中文名、标签不压物件 | 让标签压在物件上 |
| ⑤ 排除项 | 不要投影、不要边框、不要水印、不要文字（除标签）、不要第二个人、不要装饰陪衬 | 写成长串互相矛盾的禁止词 |

**拼版（工具板 / 多视图）变体**：②改成「3 列 2 行共 6 件，正交俯视无透视，同一光线同一比例」；④写「每件占格内八成，不跨格、不重叠，正下方留白标名」。一张 4–12 件，超过 12 件分两张。

**数量反推**（3:2 / 2K ≈ 2048×1365）：6 件每格约 680×680 够看清材质；9 件约 680×450 够用；12 件约 512×455 只够认款式。

## 3. 视频卡（`单元\U01.md`）

### 3.1 骨架（从第 1 行开始，逐字照这个结构）

````markdown
# U02｜拆旧·夯基·立模

> 本卡版本：v01
> 生产状态：定稿
> 生成：15 秒｜Seedance 2.0 Mini｜9:16｜480P｜声音开
> 上传顺序：1 主角身份（已有） = 项目文件夹\生成\RC01_主角四视图_v01.png｜2 工具与材料 = 项目文件夹\生成\RC04_工具与材料板_v01.png｜3 当前阶段S1拆除后 = 项目文件夹\生成\RC05_阶段S1拆除后_v01.png｜4 目标阶段S2模板立好 = 项目文件夹\生成\RC06_阶段S2模板立好_v01.png
> 输出文件名：U02_v01.mp4

## 拼好的完整正文

```text
（视频提示词正文，十块，见 3.4）
```
````

### 3.2 五个头部字段

| 字段 | 必须写成 | 错法 → 后果 |
|---|---|---|
| 本卡版本 | `> 本卡版本：v01` | `v01 已写`、`第1版` → **不导入** |
| 生产状态 | `> 生产状态：定稿` | 含「草稿／暂缓／不可提交」→ 按草稿处理 |
| 生成 | `> 生成：15 秒｜模型｜9:16｜480P｜声音开` | 开头不是「数字 秒」→ **不导入**；`约 15 秒`、`十五秒`、`15` 都错 |
| 上传顺序 | `> 上传顺序：1 名称 = 路径｜2 名称 = 路径` | 拆不开 → **整批导入中断** |
| 输出文件名 | `> 输出文件名：U02_v01.mp4` | 不写就默认 `U02_v01.mp4`，容易撞名 |

- 五个字段必须在前 **15 行**内、以 `>` 开头。
- **字段名只有这五个字**：`生成参数：`、`参考图：`、`时长：` 一律不认。
- `生成` 后面**按长相认、不按位置**：`9:16` → 比例；`480P` → 清晰度；`声音…` → 声音；**含英文字母的** → 模型。
- 网页只认整秒。写 `15.4 秒` 会被向上取整成 16 秒并记备注，能跑但不是你想要的那条，别写小数。

### 3.3 上传顺序：八条硬规则

1. **整行必须是一行**，中间不能换行。
2. 每段格式固定 `数字 空格 名称 = 路径`，编号从 1 连续。
3. `=` **左边**是素材名称，注解随便写：`1 主角身份（工人·已有）`。
4. `=` **右边**只有路径，**到扩展名结束**：`.png` / `.jpg` / `.jpeg` / `.webp`。
   - ✅ `项目文件夹\生成\RC01_主角四视图_v01.png`
   - ❌ `项目文件夹\生成\RC01_主角四视图_v01.png（已有）` ← 2026-11-01 三条视频就是这么被跳过的
   - ❌ `项目文件夹\生成\缺`（占位符不是路径）
5. 名称里不能有 `=`；路径里不能有 `｜` 或 `|`。
6. 两种路径写法，`项目文件夹` 是字面前缀，程序会替换成真实路径：
   - 已有原图：`项目文件夹\准确文件名.png`
   - 上游生成图：`项目文件夹\生成\RC编号_准确名称_v01.png`
7. 张数 ≤ **4**（网站在线生成一次最多 4 张）。
8. 顺序 = 网页上传顺序 = 正文里「第 N 张图」的编号，**必须一一对应**。

> 程序现在会兜底去掉路径尾巴的括号注解，但**不要依赖兜底**——注解永远写左边。

### 3.4 视频提示词正文：十块，顺序固定

每块以 `【块名】` 单独一行开头。块名和顺序不能改，程序和人读表都按这个认。

| # | 块 | 写什么 |
|---|---|---|
| 1 | `【画面规范】` | 画幅、时长、机位运动（固定/轻微手持）、切点方式、不出现文字水印卡面痕迹 |
| 2 | `【参考图职责】` | 逐张写「第 N 张（RCxx 名称）：**只借**什么，**不借**什么」，张数 = 上传顺序张数 |
| 3 | `【人物】` | 谁、多大、穿什么；**和参考卡不一样的地方必须明说**（"不借卡上的军绿衬衫"）；谁不在画面 |
| 4 | `【空间与空间合同】` | 方位（门在上方/步道在下方）、相机在哪一侧、不越过哪条线 |
| 5 | `【阶段】` | 本单元从什么状态到什么状态；开始时有没有 X，结束时有没有 Y |
| 6 | `【镜头N｜X 秒｜景别｜机位高｜俯仰｜焦段｜固定】` | 每个镜头一块，块内四行：`本刀占素材 A–B 秒`／`起点：`／`那一个动作：`／`终点：` |
| 7 | `【风格与光线】` | 真实生活摄影质感、光源方向、色温；不写"电影感" |
| 8 | `【声音】` | 动作声随动作起停 + 底声 + 有没有音乐/对白；画面没有电钻就不写钻声 |
| 9 | `【稳定约束】` | 外观、服装、空间一致性；不许新增元素 |
| 10 | `【负向约束】` | 只针对本单元**真实风险**的 3–8 条，不抄长串万能禁止词 |

**镜头块的硬约束**

- 各镜头时长之和 = `生成` 的秒数（差 ≤0.1）。**写不满的那几秒，模型会自己编走位和静止。**
- 每刀**动作数 = 1**。写两个动作就退回小分镜重写，不许在这里合并。
- 相邻两刀**景别必须不同**（近景 ↔ 中景 ↔ 全景）。只挪机位不换景别，观众看不见这个切，模型会连成一条长镜头。
- 切点单独一行：`⚠️硬切至镜头N：一帧完成，不许推拉、不许摇、不许渐变、不许叠化、不许闪白`。
- 起点写**画面里看得见的物件**，不写"准备""走过来""站好""直起腰"。
- 动作写**那一下**（锤头落下去），不写"完成后"（台阶已经没了）。
- 状态跳跃只能用三种合法出口：A 上一刀画面里已经看见／B 这一刀自己演得完／C 结果镜头重新起手（人是静的）。否则模型会自己编一段过渡，全要剪掉。

**正文里禁止出现**

`{{占位}}`、`同上`、`见上文`、`待补`、`参考之前版本`、解释性旁白、给用户的操作建议、小分镜里没有的动作。

## 4. 路径与依赖

| 情况 | 写法 |
|---|---|
| 已有原图（在项目根） | `项目文件夹\人物参考.png` |
| 上游生成的图 | `项目文件夹\生成\RC05_阶段S1拆除后_v01.png` |

- 下游引用必须和上游 `输出：生成\X.png` **一个字不差**（只多一个 `项目文件夹\` 前缀）。
- 依赖不能成环；不引用 `生成\_待审\` 里的图。
- 还没生成的图可以引用，但**必须有对应的上游 RC 卡**；没有上游卡 → 生产时判「等派生输入」，无限期跳过。
- 找不到就列缺口，**不许猜成相似文件名**。

## 5. 一票否决清单（写错就废）

| # | 错法 | 后果 |
|---|---|---|
| 1 | 路径尾巴带 `（已有）` `（第1张）` | 静默跳过，显示「完成」 |
| 2 | 上传顺序换行写成两行 | 整批中断 |
| 3 | 上传顺序某段缺 `=` | 整批中断 |
| 4 | `生成：约 15 秒` | 不导入 |
| 5 | `本卡版本：第1版` | 不导入 |
| 6 | 缺 `## 拼好的完整正文` | 不导入 |
| 7 | 正文里有 `{{}}` | 不导入 |
| 8 | 引用一个既不存在、又没有上游卡的图 | 静默跳过 |
| 9 | 镜头时长之和 ≠ 生成秒 | 多出的秒被模型自己编 |
| 10 | 正文写「图4」但只传 3 张 | 审计拦或模型瞎猜 |
| 11 | 父图/输出栏里出现括号文件名 | 括号被删，路径错 |
| 12 | `单元\` 里放说明书 | 每次多一条「不导入」 |

## 6. 交付前自检

**AI 自查（逐条回答，写进 `导入核对清单.md`）**

1. 五个头部字段齐全、都在前 15 行、都以 `> ` 开头、字段名一字不改？
2. `生成` 第一个字段是「数字 秒」，没有「约」、没有小数？
3. 上传顺序是**一行**？每段都是 `数字 名称 = 路径`？编号 1..n 连续？
4. 每个路径都以图片扩展名**结尾**？注解全在 `=` 左边？
5. 每条路径要么文件真实存在，要么对应某张 RC 卡的 `输出：`？
6. 参考图 ≤4 张？正文里「第 N 张」最大编号 ≤ 实际张数？
7. 正文只有一个代码块？没有 `{{}}`、没有"同上"？
8. 各镜头时长之和 = 生成秒？每刀只有 1 个动作？相邻景别不同？
9. 编号、版本、输出文件名三者一致（`U02.md` / `v01` / `U02_v01.mp4`）？
10. `单元\` 里只有 U*.md？

### 7.2 视频卡（节选：头部 + 前两块 + 一个镜头块）

````markdown
# U02｜拆旧·夯基·立模

> 本卡版本：v01
> 生产状态：定稿
> 生成：15 秒｜Seedance 2.0 Mini｜9:16｜480P｜声音开
> 上传顺序：1 主角身份（已有） = 项目文件夹\生成\RC01_主角四视图_v01.png｜2 工具与材料 = 项目文件夹\生成\RC04_工具与材料板_v01.png｜3 当前阶段S1拆除后 = 项目文件夹\生成\RC05_阶段S1拆除后_v01.png｜4 目标阶段S2模板立好 = 项目文件夹\生成\RC06_阶段S2模板立好_v01.png
> 输出文件名：U02_v01.mp4

## 拼好的完整正文

```text
【画面规范】
输出正常满屏 9:16 竖幅连续视频，15 秒。画面里不出现参考卡的标题、编号、分区线、边框或拼图痕迹，不出现任何文字、字幕、水印。七个镜头全部固定机位，不推、不拉、不摇、不跟、不变焦，只允许不超过画面高度 1% 的手持抖动。镜头之间硬切。

【参考图职责】
````
